# 🪙 Coin Collector Game

A 2D arcade-style game where players navigate a character across the screen to collect as many coins as possible while dodging obstacles before time runs out.

---

## 🎮 Gameplay & Features

- **Dynamic Spawning:** Coins and obstacles spawn randomly across the screen.
- **Score Tracking:** Real-time score counter and high-score persistence using LocalStorage.
- **Time Attack:** 60-second countdown timer to test player reflexes.
- **Sound Effects:** Audio cues for collecting coins, collisions, and game over.

---

## 🕹️ Controls

| Action | Key (Desktop) |
|---|---|
| Move Left | `A` or `Left Arrow` |
| Move Right | `D` or `Right Arrow` |
| Jump | `W` or `Spacebar` |
| Pause Game | `Esc` or `P` |

---

## 🛠️ Built With

- **HTML5 Canvas** - Game rendering and animations
- **JavaScript (ES6+)** - Game loop, collision detection, and physics
- **CSS3** - HUD styling and responsive layout
